Areas Caesey flagged as still weak or undecided for [[open-inference-company-thesis]] (as of 2026-08-29):

Still learning: inference mechanics (weights → production request); inference economics (GPU cost, batching,
throughput, latency, utilisation → COGS); how GPU capacity is actually purchased/negotiated; production ops;
which Australian customers actually buy and why; long-term market structure.

Undecided: first model(s), catalogue size, first compute provider, shared vs dedicated vs private inference as
the launch product, API architecture, pricing, vertical, name, capital requirements, GPU commitments, launch
timing, whether day-zero deployment matters commercially, how big fine-tune hosting gets, whether to ever own
infrastructure, GTM.

**Why:** He wants conversations to start from real open questions rather than re-deriving settled context, and
he explicitly invites challenge.

**How to apply:** Don't present these as decided. Any COGS model is hypothetical until real supplier quotes and
a real deployment exist — say so rather than producing confident unit economics.
